## Details

**Prompt Injection and Adversarial Attacks**

Prompt injection is the primary attack vector for LLM-based applications: malicious inputs designed to manipulate model behaviour, bypass safety guardrails, or extract sensitive information. Janet's contributions to Lakera's 2025 GenAI Security Readiness Report focused specifically on prompt injection testing methodologies, drawing on her QA background to bring systematic, evidence-based testing practices to a domain that often lacks them. Her approach treats prompt injection testing as a structured quality assurance discipline, not an ad-hoc exercise.

**Enterprise AI Security Implementation**

Janet applies security-first principles to AI system design: rate limiting, input validation, output filtering, prompt injection protection, and secure logging. Maya itself is built on this architecture, serving as a live demonstration of production-ready AI security practices: optional Opt-in conversation logging only when the user consents (EU storage, 90-day retention; chat available without saving), automated IP protection checks, comprehensive error handling, and security-hardened API design. See `docs/context/maya-product-transparency.md` for Maya's product privacy and Opt-in details.

**Regulatory and Governance Context**

AI security in the EU context cannot be separated from GDPR and the EU AI Act. Janet integrates regulatory compliance into her security advisory work: what constitutes a high-risk AI system under the EU AI Act, what data handling obligations apply when AI processes personal data, and how organisations build defensible AI deployment practices that satisfy both security and compliance requirements.

**AI Security in Education**

Janet teaches AI security principles embedded in her IADT curriculum (not as a standalone module but woven into Enterprise Cloud and Generative AI) and in her SOLAS Level 5 programme. Topics include hallucination detection, the distinction between capability and reliability, GDPR obligations in AI tool use, and how to evaluate whether an AI system's outputs are trustworthy for a given business context.
