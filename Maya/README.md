# Maya - Janet's Digital Twin

ChatGPT-like interface for Janet Xiu Shi's Digital Twin, powered by AI Builders API.

## 📚 Documentation

For implementation details, see the project repository documentation.

## 🚀 Quick Start

### Backend

```bash
cd Maya/backend
npm install
cp .env.example .env
# Edit .env and add your AI_BUILDER_TOKEN
npm start
```

### Restart Backend Server

```bash
cd Maya/backend
./stop.sh && ./start.sh
```

### Frontend

Open in browser: `http://localhost:3001/maya.html`
